# Gujarat Tuition Exam Portal Client Presentation Plan

## Audience
- Tuition class owner / institute admin in Gujarat
- Teaching staff evaluating business value and practicality

## Objective
- Present a smart exam platform concept in a way that is easy for a tuition class to understand
- Emphasize operational simplicity, student performance improvement, and parent-visible value

## Narrative Arc
1. Current problems tuition classes face
2. Product vision as a test + analysis + improvement system
3. How the platform works for admin, teacher, and student
4. What is included in MVP
5. What makes the solution stronger than a normal exam portal
6. Delivery approach and next steps

## Slide List
1. Title slide
2. Market pain / current challenges
3. Our proposed solution
4. User roles and how each benefits
5. Core MVP features
6. Dynamic exam generation workflow
7. Evaluation and analytics
8. Differentiators for Gujarat tuition classes
9. Delivery roadmap
10. Closing / next steps

## Visual System
- Clean modern business presentation
- White and deep navy base with saffron, teal, and emerald accents
- Rounded cards, subtle gradients, optimistic academic tone
- Typography:
  - Titles: Poppins
  - Body: Lato

## Image Plan
- Slide 1: abstract academic technology hero plate, text-free
- Slide 3: dashboard-inspired education operations visual plate, text-free
- Slide 8: Gujarat tuition context visual plate with subtle academic energy, text-free

## Editability Plan
- All titles, bullets, labels, timelines, and diagrams remain editable PowerPoint text/shapes
- Only atmospheric hero/background visuals use generated images

## Output
- Final editable `.pptx` deck for client sharing and revision
